# Advertising Guide

How to prepare an image for a Reconnect advert.

## How the image is shown

Every card is the same width. Only the height changes, so the same image is
cropped to a different shape depending on the advert size you pick. The image
fills its box and is cropped (never stretched), and the crop is centred
horizontally and sits towards the top (about 25% down) vertically.

The sizes below are what the cards measure on a desktop screen. They shift a
little on phones and tablets, so treat them as a guide to the **shape**, not an
exact pixel size.

| Advert size | Shape on screen | Typical box | Ratio | Export at (2x for sharp screens) |
|---|---|---|---|---|
| Feed Small | Wide, short strip | 280 x 63 px | about 4:1 | 800 x 200 px |
| Feed Medium | Roughly square | 280 x 315 px | about 1:1 | 800 x 900 px |
| Feed Large | Tall portrait | 280 x 567 px | about 1:2 | 800 x 1600 px |

## Tips for each size

- **Small:** the strip is very short. Use a wide banner with a logo or a few
  words in the middle. Anything near the top or bottom edge can be cut off, so
  keep the important part in the centre band.
- **Medium:** a square-ish image works best. Keep faces, logos and text away
  from the edges.
- **Large:** a tall poster style image. Put the key content in the upper two
  thirds, because the crop favours the top.

For all sizes:

- Keep text large and short. The card also shows the advert message under the
  image, so the image does not need to carry the full pitch.
- Leave a safe margin of roughly 10% on every edge.
- Avoid a background that matches the white card, so the image reads as an
  image.
- If an advert has no image it is shown as a small text card.

## File types and size

- JPG, PNG, WebP and **GIF** are all fine. Animated GIFs play on the card.
- Aim for **under 1 MB** per image, and keep animated GIFs under 2 MB. Large
  files slow down the page, which holds up to 100 cards.
- Use the dimensions in the table rather than a much bigger image. A bigger
  file looks the same and loads slower.

## Checklist before uploading

1. Pick the advert size (Feed Small, Medium or Large) first.
2. Export the image at the size in the table.
3. Check that nothing important sits within 10% of the edges.
4. Check the file is under the size limit.
5. Upload it in the admin, then preview the advert on the front page.

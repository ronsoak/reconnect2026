Using Reconnect

Discover articles

  • Dynamic mixes new, older, and popular articles. Refresh it for another selection.
  • Newest shows the latest articles first.
  • Popular orders articles by rank, influenced by reader clicks.
  • Choose Category and Focus options, then select Apply to narrow the feed. Reset clears your choices.
  • Use the search bar on any page to find article titles or publication names. Search ignores your feed filters.

Article links take you to the original publication. Browse the Publications directory to find a site's own website, RSS feed, and articles.

Read through RSS

Copy a feed link from the Publications page into your preferred RSS reader. Follow all articles or choose a category. Reconnect's feeds include up to {{ rss_feed_item_limit }} of the newest articles with publication dates; individual publications also have their own source feeds.

Use the API

The public, read-only API returns JSON without requiring an account. Start with these endpoints:

  • /api/feed/ for the article feed.
  • /api/search/?q=games for search results.
  • /api/filters/ for category and Focus IDs.

Choose an ordering with ?feed=newest or ?feed=popular. Filter with category and tag IDs; repeat either parameter to select more than one. Use page for additional Newest, Popular, or search results.
